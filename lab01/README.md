# Практическая работа № 1

Знакомство с языком Си. Структура программы, вывод, переменные и функции.

Мухаметжанов Александр, группа ИВ-622.

Каждое задание находится в отдельном файле: `pw01-1.c` — задание 1.1, `pw01-2.c` — 1.2 и так далее до `pw01-10.c`.

## Запуск на Linux

Нужен компилятор GCC. В терминале, открытом в этой папке:

```sh
sh build.sh
./build/pw01-1
```

Первая команда собирает все задания. Вторая запускает первое. Для другого задания нужно заменить номер, например:

```sh
./build/pw01-6
```

Собрать одно задание вручную:

```sh
mkdir -p build
gcc -std=c11 -Wall -Wextra pw01-1.c -o build/pw01-1
./build/pw01-1
```

## Запуск на Windows

Для сборки нужен установленный компилятор C/C++ из Visual Studio.

Двойной щелчок по `run-all.cmd` собирает и запускает задания по очереди. После каждого задания нужно нажать любую клавишу.

Для запуска через Visual Studio создаётся пустой проект C++ и в него добавляется один файл `.c`. Затем: Ctrl+Shift+B — сборка, Ctrl+F5 — запуск. Каждое задание содержит свой `main`, поэтому все десять файлов вместе в один исполняемый проект не добавляются.

## Данные и примечания

- В задании 1.2 указано «Мухаметжанов А.», так как отчество не задано. Последняя строка оформлена по примеру таблицы: `]А. Мухаметжанов[`.
- В задании 1.3 имя — Александр, группа — ИВ-622, компьютер — WIN-6GRCL6DJEK6. Использованы символы табуляции.
- Суммы в 1.3 равны 10 и 23: считаются данные до скобок, включая табуляцию (один символ). Первая строка: 9 букв + 1 табуляция = 10. Вторая: 6 символов группы + 1 табуляция + 15 символов hostname + 1 табуляция = 23. Запись самой суммы и завершающий перенос не учитываются, как в первой строке примера методички. Формулировка о длине всей строки допускает другое чтение; при включении скобок и цифр суммы значения были бы 14 и 27.
- В задании 1.6 возраст — 17 лет. Использованы коэффициенты из условия: 365 дней, 24 часа, 3600 секунд. Результат: 6205 дней, 148920 часов, 536112000 секунд.
- В задании 1.10 `NODE_ID` равен 42: размер пакета 168, объём передачи 504.
